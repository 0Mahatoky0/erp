# Init frontend (scaffold Vite d'origine)

Ce dossier est une copie **intacte** du frontend initial cree par Vite (commit `init frontend`).

Il n'est **pas** utilise par l'application : il est conserve pour que l'equipe puisse
reprendre les styles d'origine (`src/assets/base.css`, `src/assets/main.css`), les
composants de demonstration (`HelloWorld`, `TheWelcome`, `WelcomeItem`, icones) et la
structure de depart du projet.

Pour demarrer l'application, c'est le dossier `frontend/` qu'il faut lancer :

```bash
cd frontend
npm install
npm run dev
```
